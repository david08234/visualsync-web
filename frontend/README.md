# VisualSync - Sistema Web Fotográfico

## Descripción

Aplicación web diseñada para la gestión de servicios fotográficos profesionales, permitiendo administrar portafolios, agendar reservas de sesiones, validar comprobantes de pago por QR y entregar galerías digitales en alta resolución a los clientes.
